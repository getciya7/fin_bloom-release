# FinBloom releases

Downloads for the FinBloom personal finance app. The app checks this repository for updates.

## Install
1. On your Android phone (Android 8 or newer), download [finbloom.apk](../../raw/main/finbloom.apk).
2. Open it, and allow your browser to install apps when Android asks.
3. If Play Protect asks to scan the app, choose to scan it.

Later versions are offered inside the app.
